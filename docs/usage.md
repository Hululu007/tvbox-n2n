# 桌面版（TKLauncher）使用说明

> 面向最终用户（电视盒子 / 智能电视）的操作手册。组网（n2n）详细说明见 [hin2n.md](file:///f:/tvbox-n2n/docs/hin2n.md)，接口与配置开发说明见 [tvbox-dev.md](file:///f:/tvbox-n2n/docs/tvbox-dev.md)。

---

## 1. 这是什么

TKLauncher 是电视端影视聚合 + 桌面应用。安装后：

- 应用名称为「**桌面**」，包名为 `TKLauncher.app`（海信版 `TKLauncher.hisense`），可与其它 TVBox 并存安装；
- 安装后直接出现在系统桌面选择器，可作为系统桌面使用（参考 MQLauncher 的 HOME 声明方式），**不再有应用内「选择桌面/设为桌面」开关**；
- 点播、直播、搜索、收藏、播放历史、应用市场、hin2n 组网等功能齐全；
- **首页推荐默认多行网格显示**；
- **点播界面直接显示点播分类；切换影视源后在当前点播界面原地重载（复用缓存配置 + 重载插件 + 刷新分类），不返回首页**；
- **应用内没有设置页和任何设置入口**：全部功能设置由 JSON 下发（远程或本地）；
- 安装包**不内置任何配置 JSON**，未配置时使用程序默认值；
- 所有接口支持密文下发；所有请求自动携带系统版本、MAC、IP、App 版本。

## 2. 安装与选包

### 2.1 该下载哪个 APK？

文件名形如 `TKLauncher_release-<品牌>-<模式>-<架构>.apk`：

| 维度 | 选择 |
|------|------|
| 品牌 | 普通设备选 **generic**（包名 `TKLauncher.app`）；海信定制机型选 **hisense**（包名 `TKLauncher.hisense`） |
| 模式 | 一般设备选 **normal**（文件名显示 java，Android 4.4 起可用）；需要 Python 影视源选 **python**（Android 5.0 及以上） |
| 架构 | 32 位设备选 **v7a**（armeabi-v7a）；64 位设备选 **arm64**（arm64-v8a） |

> 每个品牌×模式都会分别产出 32 位与 64 位两个 APK。多数电视盒子为 64 位；老设备选 v7a。

### 2.2 安装

1. 把 APK 拷到 U 盘，用文件管理器打开安装；或使用盒子自带的应用安装功能。
2. 如系统提示「禁止安装未知来源应用」，允许「桌面」安装后返回，安装会自动继续。
3. 安装后在应用列表找到「**桌面**」打开。
4. 按主页键时，系统若弹出桌面选择，选择「桌面」并确认「始终」即可；之后按主页键直接回桌面。

### 2.3 应用内下载安装

应用市场、升级包、配置中的第三方 App 都支持应用内下载：

- 下载时屏幕顶部显示进度条，可继续使用其他功能；
- 下载完成自动调起系统安装；
- Android 8+ 首次安装需允许「安装未知应用」。

## 3. 配置从哪来（没有设置页）

本版本**移除了应用内全部设置入口**。配置统一在 JSON 文件中维护：

- 开发者编译时在 [RemoteConfig.java](file:///f:/tvbox-n2n/app/src/main/java/com/github/tvbox/osc/n2n/RemoteConfig.java) 的 `CONFIG_URL` 常量填写配置地址；
- 支持三种来源：
  - **远程**：`http://...` / `https://...`（推荐，可热更新，断网时使用上次缓存）；
  - **本地文件**：如 `/sdcard/TKLauncher.app/config.json` 或 `file:///...`；
  - **APK 资源**：`assets/xxx.json`（仅当确实需要随包携带配置时）；
- `CONFIG_URL` 留空 = 不加载配置，使用程序默认值；
- JSON 支持注释（`//`、`/* */`）和尾逗号。

完整字段、所有接口地址、配置示例与 PHP 服务端示例见：

- [配置示例 tvbox-config.example.jsonc](file:///f:/tvbox-n2n/docs/tvbox-config.example.jsonc)
- [接口与配置开发文档 tvbox-dev.md](file:///f:/tvbox-n2n/docs/tvbox-dev.md)
- [PHP 接口 demo](file:///f:/tvbox-n2n/docs/php-demo/)

### 3.1 关键字段

| 字段 | 说明 |
|------|------|
| `api` | 主点播接口地址（本地配置时其它接口的相对地址以它的域名/IP 为基准） |
| `live` | 直播源（txt / m3u / json 地址） |
| `epg` | 节目单地址 |
| `proxy` | 播放代理（可选） |
| `settings` | 全部功能设置（详见开发文档） |
| `topEntries` / `homeEntries` | 顶栏 / 历史行入口（可配置，也可整体替换） |
| `appMarket` | 应用市场列表/详情接口或直接下发 apps 数组 |
| `upgrade` | 升级检查接口 |
| `notice` / `home` / `themes` / `donate` | 公告、首页外观、主题、捐助页 |
| `screens` / `defaultScreen` | 酒店 IPTV 桌面（每屏独立接口 + 布局插件，见 §4.1） |
| `remoteConfigUrl` | 可选的二次远程配置覆盖 |

> 滚动公告对象还支持 `pause`（整条公告完整走完一遍后停顿的秒数）、`speed`（像素/秒）、
> `duration`（自动隐藏秒数）、`show`（按首页/直播/点播/酒店分别开关）。
> 修改后立即重启滚动，无需重启 App。

> **相对地址规则**：`live`、`epg`、`proxy`、`upgrade.checkUrl`、`appMarket.url/detailUrl`、自定义点播入口等，未写 `http://` 或 `https://` 时，**优先拼接主配置来源地址**（`CONFIG_URL` / `remoteConfigUrl`）的协议 + 域名/IP + 所在目录；配置来自本地文件/assets 时回退拼接主接口 `api` 的域名/IP。例如主配置地址为 `http://1.2.3.4:8080/php-demo/index.php?r=config`，`live = index.php?r=live` → `http://1.2.3.4:8080/php-demo/index.php?r=live`。

> **接口加密**：以上接口返回内容可以是明文 JSON，也可以是 `ke` 前缀密文（AES-128-ECB），客户端自动识别。

## 4. 首页导览

```
┌──────────────────────────────────────────────────┐
│ 顶栏：日期/WiFi/搜索/显示方式/主题/收藏…           │
├──────────────────────────────────────────────────┤
│ 历史 点播 直播 搜索 收藏 推送 文件 组网 系统 捐助  │
│  ── 影视推荐内容（默认多行网格） ──                │
└──────────────────────────────────────────────────┘
```

- **历史**：播放记录，可继续观看；
- **点播 / 直播 / 搜索**：进入对应功能；
- **收藏**：收藏的影视；**推送**：手机/电脑推送的点播链接；
- **文件**：本地文件浏览；
- **组网**：hin2n 组网（见 §10）；
- **系统**：打开 Android 系统设置（网络、显示、日期等）；
- **捐助**：项目介绍与收款二维码（由 JSON 配置）；
- 首页入口行与顶栏可由 JSON 的 `homeEntries` / `topEntries` 整体替换；
- 首页推荐默认**多行**；可用 JSON `settings.homeRecStyle = false` 改为单行；
- 未配置点播接口时也可把本机当作纯直播盒子使用。

### 4.1 酒店 IPTV 桌面（可选）

主配置配置了 `screens` 且 `defaultScreen` 指向其中一个 `id` 时，启动直接进入酒店桌面：

- 三种内置布局：`hotel_grid`（宫格）、`hotel_list`（左菜单+右大图）、`hotel_showcase`（顶部大图）；
- 每个界面可用独立的 `api` / `live` / `epg`，切换界面后立即生效；
- 外观与入口可拆到 `screens[].layoutUrl` 布局插件 JSON，改 JSON 即换肤，无需发版；
- 入口支持 `page` / `feature`（含 `screenSwitch` 切换界面）/ `app`（拉起或下载安装第三方 APK）/ `vod`；
- 底部滚动通知优先用 `screens[].ticker`，为空时回退全局 `notice`；
- 切换界面弹窗会自动勾选当前所在界面。

从零教程与可直接运行的 demo：

- [酒店界面与布局插件完整开发指南](file:///f:/tvbox-n2n/docs/hotel-dev-guide.md)
- [酒店 demo 配置](file:///f:/tvbox-n2n/docs/demo/hotel/config.json)

## 5. 点播

1. 首页选「**点播**」；
2. 进入点播会先显示**启动等待画面**（可在主接口 `vodSplash` 配置背景图/文案/时长），点播接口和当前源插件加载完成后自动进入分类并加载数据；
3. 点播界面第一个分类是「**热播推荐**」，固定显示并默认选中，数据与主界面推荐设置完全一致：
   - 主接口配置了 `home.recMovies` → 使用接口推荐内容；
   - 未配置 → 回退豆瓣热播（按天缓存）；
   - `settings.homeRec=2` → 使用观看历史；
4. 点播页左上角/菜单可**切换影视源**：
   - 切换后提示「已切换到「源名」」；
   - 与 TVboxOSC 一致：选源后**重启点播界面**，按新源重新加载分类与热播推荐；
   - 不支持的源类型、隐藏源（`hide=1`）、空接口源不会出现在切换列表；
4.1 点播界面右上角**齿轮图标**可打开「点播源配置」：填写点播接口地址，或使用对话框中的二维码手机扫码配置（手机改完立即生效）；
4.2 主接口配置了酒店 IPTV 桌面（`screens` + `defaultScreen`）时，启动会直接进入对应桌面布局；每个界面可使用独立接口；
5. 进入影片：选择剧集 → 选择播放线路 → 开始播放；
6. 播放页遥控器：

| 按键 | 作用 |
|------|------|
| 左右 | 拖动进度（视源支持） |
| 上下 | 切换选集 / 音量 |
| OK | 显示/隐藏控制栏与选集 |
| MENU | 播放设置（解码器、播放器、倍速等） |
| 返回 | 退出全屏控制，再按返回列表 |

7. 收藏与播放历史自动记录。
8. **网页源播放**：若播放地址为 `webview://`、`video://` 或 `tkp2p://`，播放页会自动切换到 WebView 播放层；
   遥控器返回键优先退出网页全屏，再退出播放页。

> 点播接口的所有提示（加载成功/失败、免责声明、切源提示）只在点播界面出现，首页不再提示；主接口无法访问且无缓存时会直接显示全屏报错页，可重试或退出。
> JSON 可配置专用点播入口（`type=vod`），使用独立影视源与独立主题，不影响首页主源。

## 6. 直播

进入「直播」后默认播放上次频道。

| 按键 | 作用 |
|------|------|
| OK（短按） | 频道列表：上下选台，左右切分组 |
| 长按 OK（网页源） | 在网页界面与全屏视频间切换 |
| MENU | 直播设置：线路、解码、画面比例、换台反转、退出等；原「直播历史」已改为「直播源配置」入口 |
| 上/下 | 上一个/下一个频道 |
| 右 | 切换下一条直播线路 |
| 数字 0–9 | 直接输入频道号 |
| 返回 | 退出直播 |

触摸设备：点左 1/3 调频道列表，点中 1/3 显示频道信息，点右 1/3 打开直播设置。

- 黑屏/卡顿：MENU → 节目源解码切换系统/硬解/软解/EXO，或右键换线路；
- 直播接口兼容 **JSON / txt / m3u**：`live` 填 .txt 或 m3u 地址可直接识别；
- 接口可在每个频道/线路下发 `decode`（soft/hard/system/exo/ali/auto）作为该线路默认解码，用户在播放中手动调整后以用户设置为准；
- P2P 直播（`tkp2p://`）：首次启动需数秒建立连接；
- 网页型源：长按 OK 进入网页界面操作；
- MENU →「直播源配置」可填写直播源地址与 EPG 地址，并支持二维码手机扫码配置；
  保存后自动重启直播界面并按新配置重新加载；用户手动配置默认优先于主接口（除非主接口 `forceOverride=true`）。

### 6.1 节目单（EPG）

- 频道列表右侧显示节目单，默认昨天/今天/明天，天数由 JSON `epgDays` 控制（1~9）；
- 节目单缓存到本机，同一天不重复请求；
- 点击已结束节目，支持时移/回看的源会自动带 `playseek` 回看地址。

## 7. 搜索

- 「快搜」：多源聚合搜索；
- TV 端使用屏幕键盘，可输入首字母/全拼，方向键选词、OK 确认。

## 8. 主题与外观

- 顶栏「主题」图标可切换内置主题，立即生效；
- JSON `themes` 可覆盖内置主题或追加自定义主题，支持多背景图随机切换；
- JSON `home` 可配置背景图、入口颜色、图标颜色、文字颜色、透明度、推荐影片；
- 左上角名称由主接口 `home.sourceName` 统一定义；首页推荐数据由主接口 `home.recMovies` 直接提供（配置后不再请求豆瓣，主页面也不再引用点播接口数据）；
- 全部外观随配置下发，应用内不再提供外观设置页。

## 9. 应用市场（「应用」页面）

首页「**应用**」入口进入应用市场：

| Tab | 内容 |
|-----|------|
| 精选 | 推荐应用（`recommend`） |
| 应用 | `category=app` |
| 游戏 | `category=game` |
| 排行 | 按下载量（`sort=download`） |
| 管理 | 本机已安装应用，可启动/卸载/更新 |

- **TV 搜索**：点顶部「搜索」后弹出带 **A-Z、0-9、删除、清空** 的屏幕键盘；遥控器方向键移动焦点、OK 输入，**可直接按应用首字母搜索**，无需软键盘；
- 搜索与当前分类叠加过滤，确认后显示结果，切回 Tab 恢复分类列表；
- 详情底部按钮随状态显示「安装 / 更新 / 打开 / 下载中」；
- 「管理」Tab 长按应用进入卸载模式。

数据来源由 JSON `appMarket` 决定：

- `url` 对接应用市场列表接口，模板占位符 `{category}`、`{sort}`、`{page}`、`{pageSize}`、`{keyword}`；
- `detailUrl` 详情接口，占位符 `{packageName}`（可选）；
- `headers` 自定义请求头；`pageSize` 每页数量；
- `apps` 可直接在 JSON 中下发应用数组（无需接口）；
- **APK 内不再内置应用市场 JSON 目录**。

## 10. 组网（hin2n）

首页「组网」卡片或顶栏图标进入：连接/断开、状态与日志、多组网配置、Ping、开机自动连接、静态路由。

- 状态：黄=连接中、绿=已连接、红=失败、原色=未连接；
- 首次连接需授予 VPN 权限；
- 两端协议版本/组网名称/密钥/超节点必须一致，虚拟 IP 不能冲突；
- 详细说明见 [hin2n.md](file:///f:/tvbox-n2n/docs/hin2n.md)。

## 11. 开机自启与桌面

| 项目 | 说明 | 默认 |
|------|------|------|
| 系统桌面 | 清单直接声明 HOME/DEFAULT，安装后即可作为桌面；由系统桌面选择器管理 | 可用 |
| 开机自启 | JSON `bootStart` 控制 | 开 |
| 组网开机启动 | hin2n 页面内开关（需已授权 VPN） | 关 |

- 不再有应用内「设为桌面」开关或桌面选择列表；
- 想换回原桌面：进入 Android 系统设置 → 主页/默认应用 → 选择原桌面即可；
- 原生桌面选择器是 Android 系统行为，不属于本应用功能。

## 12. 软件升级

- JSON `upgrade` 可配置升级检查接口（`checkUrl` 支持相对地址）；
- 启动进入首页后发现新版本会弹窗显示版本号与更新内容；
- 选「立即升级」应用内下载并安装；
- `force: true` 时无取消按钮，必须升级。

## 13. 常见问题

**Q：装哪个包？**
A：Android 4.4 选 normal（文件名 java）；Android 5.0+ 需要 Python 源才选 python。按 CPU 选 `-v7a`（32 位）或 `-arm64`（64 位）。

**Q：找不到设置页？**
A：本版本已移除全部设置入口，配置统一由 JSON 下发；联系设备提供方获取配置地址，或参考开发文档自行部署。

**Q：点播打开没反应/解析失败？**
A：先切换影视源；同一影片换播放线路；MENU 更换解码器；检查网络。

**Q：切源后为什么还停留在点播界面？**
A：这是新行为：切源会在当前点播界面原地重载配置与插件并刷新分类，不再返回首页，属于预期。

**Q：应用市场搜索怎么输入？**
A：在搜索弹窗用遥控器方向键选择屏幕上的 A-Z/0-9 键，OK 输入；支持按首字母搜索。

**Q：安装后按主页键还是原桌面？**
A：首次按主页键时系统会弹出桌面选择，选择「桌面」并点「始终」；若未弹出，到系统设置 → 主页/默认应用 中切换。

**Q：JSON 配置改了不生效？**
A：确认 `CONFIG_URL` 指向正确、远程配置需设备联网、接口加密内容需与客户端 `secretKey` 一致。
点播 / 直播 / EPG 接口地址改动后会立即清缓存并通知界面重载，不需要重启 App；
其它外观/设置类字段按配置检查间隔生效，回到首页或重启 App 可立即拉到最新配置。

**Q：改了接口还要重启 App 吗？**
A：不需要。接口地址变化会立即删除点播接口缓存、清空 EPG 缓存并通知界面重新加载。

**Q：点播地址是网页/网页视频/P2P 怎么办？**
A：让源返回 `webview://`、`video://` 或 `tkp2p://` 地址即可，播放页会自动使用 WebView 播放层。
